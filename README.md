# TexColorGuard - 25TE008

A simple tool to check text color contrast and safety on different backgrounds.

## Features
- Pick text color and background color
- Live preview of your text
- Shows RGB values
- Easy to use Streamlit app

## How to Use
1. Choose text color
2. Choose background color
3. Type your text
4. See live preview

## Tech Stack
- Python
- Streamlit
